# Yifan Zhang Personal Website

This repository contains an AcademicPages-based personal academic website for Yifan Zhang.

## Main Content Files

- `_pages/about.md` - homepage biography, news, research interests, and education
- `_pages/publications.html` - generated publications page
- `_pages/cv.md` - CV page
- `_publications/` - publication and preprint entries
- `files/CV_YifanZhang.pdf` - downloadable CV
- `images/profile.png` - profile image
- `_config.yml` - site-wide name, email, affiliation, and GitHub Pages settings
- `_data/navigation.yml` - header navigation

## GitHub Pages

This site is configured for `https://YZhang239.github.io` and the repository name `YZhang239.github.io`.

After pushing to GitHub, enable GitHub Pages for the `main` branch if GitHub does not do it automatically.
